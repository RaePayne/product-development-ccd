The score card values for the score card fields on [[CPR-##]](https://corumhealth.atlassian.net/browse/CPR-##).
Each text field is limited to 255 characters in JIRA. The values are condensed from
[`[source doc]`]([source doc]), which holds the full detail.

| Field | Value |
|---|---|
| Strategy & Objective | What we want to achieve, for whom, and why it matters. |
| Situation | What happens today, what's missing, and what triggered this ask now. |
| Solution | What we'd build, in plain language. Mention what's out of scope if that helps. |
| Target Market | Who uses it and who buys it (sites, roles). |
| Market Size | How many sites/customers it applies to, plus any revenue figure. "Not yet quantified" if unknown. |
| Key Competitors | Who already offers this or will soon, and how we compare. |
| Key Success Metrics | How we'll know it worked: measurable outcomes. |
| Market Validation | Evidence the need is real: customer research, feedback, sales signals. Say if none yet. |
| Unfair Advantage | What we already have that makes this easier or better for us than for others. |
| Challenges / Risks | The main unknowns, dependencies and risks. |
| Revenue Confidence | **[0–100]** *(a number. Lower = less confident it will bring revenue; the eRx PMH example used 20 for Low.)* |
| Overall Verdict | **[Positive / Negative / Neutral]** *(JIRA dropdown. Record any conditions under Challenges / Risks.)* |
| Financial Value | **[Dropdown value]** *(e.g. Cost Avoidance. Pick the matching option from the JIRA dropdown.)* |
