# Go-to-Market Plan Template

> **Purpose:** A flexible template for creating go-to-market plans that scales from a single feature release to a full product launch. Not every section is required for every release — use the scale guide below to determine which sections apply.

---

## Scale Guide

| Section | Feature Release | Module Release | Full Product Launch |
|---|---|---|---|
| Release Overview | Required | Required | Required |
| Target Customer Segments | Optional (if unchanged) | Required | Required |
| Value Proposition & Positioning | Required | Required | Required |
| Pricing & Packaging | Optional (if unchanged) | Required | Required |
| Competitive Positioning | Optional | Required | Required |
| Customer Journey & Acquisition | Optional | Required | Required |
| Sales Enablement | Required | Required | Required |
| Launch Plan & Timeline | Required | Required | Required |
| Migration & Onboarding | Optional | Required | Required |
| Metrics & Success Criteria | Required | Required | Required |
| Risk & Mitigation | Optional | Required | Required |
